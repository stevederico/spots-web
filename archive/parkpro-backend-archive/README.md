# Spots

Rails backend for the ParkPro parking spot marketplace. Originally named Spots.

## Overview

Server-side API for ParkPro iOS app. Rails scaffolded CRUD for Spot and User models, sign up/sign in auth, spot listings with validations, and a landing page. The ParkPro iOS app syncs to this backend via Rack Core Data Sync.

## Stack

- Ruby on Rails
- SQLite/PostgreSQL
- Devise (auth)
