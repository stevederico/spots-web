# ParkPro

iOS parking spot marketplace app.

## Overview

Airbnb-style marketplace for parking spots. Browse spots on a map or list view, view listing details (price, type, description, location), pay with credit card, manage cars and transactions. User auth with profiles. Core Data synced to backend via Rack. Uses SDKit, SDLoginKit, SDScaffoldKit.

## Stack

- Objective-C, Xcode
- MapKit, CoreLocation, Core Data
- Rack Core Data Sync
- CocoaPods
- SSKeychain
